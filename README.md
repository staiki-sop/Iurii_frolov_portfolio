# Портфолио Юрия Фролова

`index.html` — самостоятельная страница без JavaScript, внешних шрифтов, библиотек и сборки. Все содержательные утверждения взяты из предоставленного задания. В игровые проекты изменения не вносились.

## Публикация в GitHub Pages — 6 шагов

1. Откройте или создайте публичный репозиторий `staiki-sop.github.io` под аккаунтом `staiki-sop`.
2. Скопируйте `index.html` и папку `assets/` в корень репозитория, не внутрь папки `portfolio/`.
3. Добавьте медиа и PDF по списку `assets/README.md`, заполните ссылки и замените заглушки по комментариям TODO.
4. Сохраните изменения в ветке `main` через Commit changes или обычный git push.
5. В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)` и Save.
6. После завершения публикации откройте https://staiki-sop.github.io/ и проверьте медиа, ссылки и мобильный вид.
