# Медиа и документы

Файлы не были предоставлены. Не кладите пустые файлы с расширениями JPG, PDF или MP4: это создаст ошибки. Папки `pulse/` и `pepel/` уже созданы.

```text
assets/
├── resume.pdf
├── pulse-dossier.pdf
├── og.jpg
├── pulse/
│   ├── pulse-1.jpg
│   ├── pulse-2.jpg
│   ├── pulse-3.jpg
│   └── pulse-4.jpg
└── pepel/
    ├── poster.jpg
    ├── pepel.mp4
    ├── pepel-1.jpg
    └── pepel-2.jpg
```

Рекомендуемые размеры, а не требования к исходникам:

| Файл | Размеры / формат | Рекомендуемый вес |
| --- | --- | --- |
| resume.pdf | PDF, текст должен выделяться | до 2 МБ |
| pulse-dossier.pdf | PDF | до 5 МБ |
| og.jpg | 1200 × 630 px, JPEG | до 250 КБ |
| pulse/pulse-1.jpg … pulse-4.jpg | 1600 × 900 px, JPEG; сохранять исходные пропорции | до 350 КБ каждый |
| pepel/poster.jpg | 1600 × 900 px, JPEG, кадр из видео | до 250 КБ |
| pepel/pepel.mp4 | MP4, H.264, 1280 × 720 или 1920 × 1080 | желательно до 25 МБ |
| pepel/pepel-1.jpg, pepel-2.jpg | 1600 × 900 px, JPEG; сохранять исходные пропорции | до 350 КБ каждый |

После добавления файлов замените соответствующие блоки `.media-slot` в `index.html` на `<img>` или `<video>` из комментариев TODO. Для каждого изображения укажите фактические размеры, содержательный `alt` и `loading="lazy"`. Для видео сохраните `controls preload="metadata" poster="assets/pepel/poster.jpg"`. При другом соотношении сторон не растягивайте кадры.

Для PDF замените неактивные `span.pending` ссылками из комментариев. Само копирование файлов не включает ссылки и галереи автоматически. После заполнения удалите соответствующие TODO. Для YouTube используйте обычную ссылку вместо встраивания: это сохраняет отсутствие внешних запросов при загрузке страницы.

Метаданные OG и Twitter уже ссылаются на `https://staiki-sop.github.io/assets/og.jpg`; файл обязателен для изображения предпросмотра ссылки.
